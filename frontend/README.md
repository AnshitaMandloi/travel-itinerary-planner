# WanderPlan AI - React (Vite + Tailwind CSS) Frontend

Modern, responsive travel planner UI built with React 19, Vite, and Tailwind CSS v4.

## Features
- **Intuitive Travel Form**: Pick destination, duration (1-14 days), travel party, budget tier, pace, and multi-select interest tags.
- **Sample Presets**: One-click quick start for Kyoto, Paris, Banff, and Amalfi.
- **Structured Day-by-Day Timeline**: Morning, afternoon, and evening activity cards with time slots, cost indicators, and local insider tips.
- **Curated Meal Recommendations**: Breakfast, lunch, and dinner suggestions per day.
- **Interactive Packing Checklist**: Check off items categorized into clothing, electronics, and comfort with live progress bar.
- **Export Capabilities**: Export structured JSON, copy summary, or print view.
- **Built-in Gemini Key Config**: Configure API key via backend `.env` or in-app session modal.

## Quick Start
```bash
npm install
npm run dev
```
Open `http://localhost:5173` in your browser.
Ensure your FastAPI backend is running on `http://localhost:8000`.
